# Sistema de Gestión de Cursos

Aplicación web para la gestión básica de cursos, desarrollada como proyecto integrador de la asignatura **Desarrollo de Aplicaciones Web Avanzado** para el primer parcial.

## Tecnologías

### Frontend
- Angular
- Bootstrap
- pnpm

### Backend
- ASP.NET Core Web API
- C#

## Estructura del proyecto

```text
sistema-gestion-cursos/
├── frontend/
└── backend/
```

## Funcionalidades principales

- Consultar cursos.
- Registrar nuevos cursos.
- Actualizar cursos existentes.
- Eliminar cursos.
- Consultar cursos por identificador.
